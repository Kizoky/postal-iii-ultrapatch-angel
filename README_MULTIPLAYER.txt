POSTAL III ULTRAPATCH ANGEL MULTIPLAYER
=======================================
Please read this before attempting to play multiplayer with your friends or anyone

Postal 3 is a game that had its Multiplayer feature canned probably very mid or late, most of the features Postal 3 built was not made
with Multiplayer in mind, so there were a lot of things to "unbreak", and even managing to fix most of the issues, multiplayer still has
issues that might or not be enjoyable as a result.

Please be aware that even though we fixed or added lot of things, we simply **cannot fix everything**

KNOWN ISSUES (AND POSSIBLE FIX) AND RANDOM QUESTIONS:
=====================================================

- Players/Clients have black textures on the map
=| Make sure the players/clients have the same copy of Postal 3, addons or mods installed, we don't know what really causes it.

- Server host/creator stuck in an endless loading loop, players/clients can connect fine
=| We don't know what causes this or how to fix it. Some maps sometimes will just refuse to load for the host.

- Delayed inputs, laggy movement, gets worse the higher your ping is
=| Postal 3 does not have client prediction, unfortunately we had to disable everything related to prediction so it feels bad.

- Server crashes when changing maps or when multiple Players connect/disconnect
=| This might be made slightly less crashaholic in the future, unfortunately the server host has to reload the game everytime to load a map.

- The higher the player count, the less the FPS counter is
=| Can't fix.

- Server crashes when multiple people are throwing grenades/items at the same time
=| Can't fix. (?)

- This "feature" does not work properly under Multiplayer
=| Let us know why it does not work, and we might (if it's fixable) fix it for the next version of Ultrapatch Angel

- Deathmatch? Game modes?
