v1.3.0: (Note: skipped version v1.2.0 on purpose, consider Ultrapatch+Angel v1.3.0 to be the main version of Ultrapatch from now on)

## Highlights  
- Made PhysX disabled by default and completely non-functional (won't fix in the future)
- New features and fixes for the AngelScript implementation
- New features and fixes for Postal3Script
- Fixed buggy Door destruction
- You can now shoot or kick while jumping
- UltraPatch Angel is now compatible with all copies of Postal 3
- Experimental Demo playback fix (Sound is working, there are some issues with the camera/prediction)
- Added new weapons (Colt, Autoshotgun, M249, Tear Gas)
- Fixed several crashes and memory corruptions
- Improved and fixed the Addon System
- Added FPS camera with FPS animations (p3_ultrapatch_cam_fps_toggle)
- Added `-novid`, skips intro videos
- Intro and credits can now be skipped
- `p3_cam_shake` console command no longer disables quake/explosion effects
- Added `-disablevideo` to completely disable (cutscene) videos in-game
- Made `func_monitor` and other such entities work again
- "Fixed" not being able to shoot while in cover mode sometimes
- Reimplemented cut Inventory system (very similar to Catharsis Reborn's implementation)
- Multiplayer fixes and new features like Teams and Spectator mode
- Players and NPCs can now open doors just by simply touching them (no need for trigger brushes anymore)
- Increased engine model (1024->4096) and sound (8192->16384) precache limits (thanks Grizzle!)
- Fixed several crashes inside materialsystem.dll and studiorender.dll (thanks Grizzle!)
- Fixed a nasty crash (somewhat rare) related to decals (thanks Grizzle!)
- New UI combined with GameUI2 and ImGui
- Fixed weapons and some other props not fading out in the same distance as NPCs do
- Heli can now start smoking and it will intensify the less health it has (feature from CR)
- Heli now always uses its Postal3Script target as shooting target
- NPCs while on Alert or Combat state will no longer move away from the Player
- Motorhead will now stick to where the Laser actually is
- Added about 41+ new P3S functions from CR, you can find some examples from here: https://github.com/WhackJobInt/postal3scriptdocs/commit/8e79d29f859cdc46f4a183a7b14e5f9611a2d545
- Dogs can now attack the Player
- Added Left 4 Dead/Alien Swarm instructor system
- Added in-game Addon/Mod Manager
- Added Ragdoll and Weapon manager which clean up lingering entities, this helps massively with performance on "battle royale" maps like `mtz`
- Implemented non-lethal attacks that is similar in implementation like Catharsis Reborn's
- NPCs can now use two-handled weapons like the shovel
- NPCs can now use throwable weapons as visible active weapons (in Vanilla they can hold a gun and throw a grenade anytime without knowing they can do that)
- Doors are now destroyed when there is an explosion near them
