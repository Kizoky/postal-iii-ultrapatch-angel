ANGEL CHANGES:
==============
v1.2.0:

* Fixed possible AS crash on server-side
* Fixed Door's parent entities not disappearing when destroyed
* AngelScript global function "Teleport" now uses the same spot check like Multiplayer spawn spot checking
* Added a bunch of null checks for the Fluids Manager to prevent crashes (Gasoline)
* Fixed black screen flashing whenever something spawned (sv_forcepreload 0)
* Fixed a bug where the save/restore system of AngelScript would be broken if you recompiled the scripts on the fly
* Fixed memory leaks in AngelScript
+ Added `ImAThrowableWeapon` P3S attribute
+ Added `ImASprayWeapon` P3S attribute
+ Added `ImAMeleeWeapon` P3S attribute
+ Added `ImAMetaWeapon` P3S attribute
+ Added `extend` P3S section, behaves like `behavior` but it can only add new states or events for an already existing behavior
* Fixed `OnTargetKilled` p3s event not working properly for NPCs
+ Added `OnTargetKilled` p3s event to work with Player death
* Active weapon no longer gets holstered when jumping
* You can now fire with any weapon while jumping/in air
* You can now kick while jumping/in air
+ Made the HUD's color customizable via scripting
+ Ultrapatch (Angel) is now compatible with all copies of Postal 3
* Fixed Player camera in Demo playback not working
+ Added Colt
+ Added Autoshotgun
+ Added M249
+ Added Tear Gas
* Fixed a crash when looking at an entity while they were being removed from the game
* Fixed a crash when running into lots of physics props (Could be replicated in shops)
+ Shovel can now get bloody like the Machete
+ Added `ea_transition` Postal3Script attribute, forces entities to travel with the Player(s) even without a single trigger_transition present
+ Added `OnInsideTransition` and `OnOutsideTransition` Postal3Script events, need `ea_transition` attribute for them to work
+ Added `ea_NoTargetSenses` for NPCs, when set the NPCs will no longer set the FSM target automatically when choosing a target for seeing, instead it will be set as the FSM Caller  
this will not work as is and will require slightly rewriting the NPCs AI (the one Akella/TM wrote)

+ Added `bool CP3SObj::IsDeleted()`, checks if a Postal3Script object has been already destroyed/deleted/destructed (it is recommended to use this if you encounter frequent crashes)
+ Added `bool CP3SObj::IsValid()`, calls `IsDeleted()` and checks if the object has been marked as destroyed (acts as a combination of `bool CBaseEntity::IsDeleted()` and `bool CP3SObj::IsDeleted()`)
* Fixed AngelScript serialization (saving script state to save file) being utterly broken
* Fixed EHANDLE object inside AngelScript crashing the game if game has been saved
* Fixed several Addon System crashes/issues
+ Added FPS camera, use `p3_ultrapatch_cam_fps_toggle` to toggle between TPS and FPS
- PhysX is no longer functional, and thus has been removed (There are no plans bringing it back)
+ Replaced the Main Menu with a custom implementation, the TV main menu (map main_menu) is unaffected
+ Added `-novid` startup parameter, completely skips intro videos playing on main menu
+ Intro/credits videos can now be skipped
* `p3_cam_shake` will no longer disable quake effects
+ Added `[HIDDEN]` metadata for AngelScript, allows certain methods or classes to be completely hidden from autocompletion
+ Added `[EXECUTABLE]` metadata for AngelScript, allows methods to be executable even if cheats is not on
+ Added Discord RPC, shows current map, current mission, current karma, and so on...
